# Pipeline 最小可行测试计划

> 目标：用最小规模验证"角色AI碰撞 → 审阅评分 → 人工判断"流水线是否可行。
> 不追求产出可用章节，只追求回答三个问题：
> 1. AI碰撞能产出什么质量的叙事？
> 2. 审阅评分标准是否可操作？
> 3. 从草稿到可用内容的人工编辑量有多大？

---

## 角色：仅两人

| 角色 | 为什么选他/她 |
|------|--------------|
| 林一 | 主角，法眼是核心叙事机制，必须测试AI能否写好"感知异常"的体验 |
| 沈青岚 | 智力最高、话术最强，与林一形成"直觉型 vs 分析型"的张力对比 |

不投入韩烈、陈表、孙尚香。减少变量，聚焦两人互动质量。

## 场景：宜都码头集市的一个切片

沿用 `scenes/yidu-market.md`，但只取**晨雾码头**这一个微环境，不涉及旧仓库、税卡冲突等大事件。

## 前提设定

林一从序章昏迷中醒来，独自走入晨雾中的码头。身上有军帐药味，伤口粗略处理过。他不知道自己为什么被放走，只想找点吃的，顺便弄清自己在哪里。

沈青岚以游医身份在码头药棚开张，正在给一名发烧的流民孩童看诊。她注意到一个从军帐方向走来的少年——身上的药味不对，不是民间药方，是军用创伤敷料。

## 触发点：一个

独臂药贩（NPC，Director控制）向沈青岚的药棚送来一批"有问题的药材"——其中混入了一种沈青岚认得的北方军用毒料。这批药材的到来打断了两人各自的节奏，迫使他们在同一个空间内产生互动。

林一的法眼可能被药材中残留的异常气息被动触发（也可能不触发——交给Agent决定）。

## 叙事结构

```
Director开场旁白（约200字）
    ↓
Free-form碰撞（5-8个节拍）
    ↓
Director收束旁白（约150字）
```

### 开场旁白锁定

Director 确立以下初始状态后交给角色Agent：

- **林一**：踩着湿滑的码头木板走入雾中，饿，冷，头还在隐隐作痛。法眼未启动。目标：找食物，搞清楚方位
- **沈青岚**：药棚内，手上有活（给孩童退烧）。警觉但不紧张。目标：完成看诊，等独臂药贩送货

### Free-form 规则

- Director 每轮选择一个角色行动，发送当前场景状态
- Director 仅做环境旁白（雾的变化、人群声音、气味）
- Director 不预设谁先开口、谁先注意到谁
- 独臂药贩在第3-4个节拍之间送药到场（Director控制的唯一剧情注入）

### 收束条件（满足任一即可）

- 两人完成一次有实质内容的对话（不是寒暄）
- 林一的法眼被触发并产生后果
- 达到8个节拍
- 某一方主动离开

## Agent配置

### Director prompt 要点

```
你是导演。本场景只有两个角色Agent（林一、沈青岚）和一个你控制的NPC（独臂药贩）。

你的职责：
1. 写开场旁白（200字内）
2. 每轮选择一个角色行动，向其发送当前场景状态
3. 写环境旁白（每轮1-2句）
4. 在第3-4节拍注入独臂药贩送药事件
5. 监测收束条件，条件满足时写收束旁白

你不做的事：
- 不替角色做决定
- 不预设对话内容
- 不强制特定结局
```

### 角色Agent加载清单

每个角色Agent收到：
1. 自己的完整角色档案
2. `scenes/yidu-market.md` 的地理风貌和环境细节部分
3. `design/style-guide.md` 的隐喻系统和禁用词
4. `content/chapter-000.md`（前情）
5. 上方"前提设定"中该角色的初始状态
6. 指令："始终以角色身份回应，不要跳出角色"

**不加载**：worldbuilding.md 全文（太重，只在需要时由Director补充品级规则）

## 产出与评估

### 产出文件
- 草稿：`content/draft-pipeline-test-<timestamp>.md`
- 审阅：`content/reviews/review-pipeline-test-<timestamp>.md`

### 测试成功标准（不是质量标准）

pipeline 测试的目标不是产出好内容，而是回答：

| 问题 | 怎么判断 |
|------|----------|
| AI碰撞能产生自然互动吗？ | 两个Agent是否产生了非预设的、合理的行为？还是机械地走流程？ |
| 角色一致性能保持吗？ | 林一说话像林一吗？沈青岚的判断逻辑符合她的人设吗？ |
| 隐喻系统能被执行吗？ | 是否出现禁用词？法眼描写是否用了经纬/纹路等隐喻？ |
| 审阅评分能区分好坏吗？ | reviewer 给出的分数和人类直觉是否一致？ |
| 人工编辑量可接受吗？ | 草稿到可读内容需要改多少？是润色级还是重写级？ |

### 测试后决策

- 如果碰撞质量可用 → 回到 `plan-chapter-001.md`，按完整计划推进
- 如果碰撞质量需调整 → 修改 Director/Agent prompt 策略，再跑一次
- 如果碰撞质量不可用 → 重新评估"AI作为创作引擎"的前提，考虑改为"AI辅助人类写作"模式
