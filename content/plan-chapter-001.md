# Chapter 001 创作计划：宜都码头集市

## 衔接：序章 → 集市

**方案 A：醒在孙尚香营中，被有意投放**

林一昏厥后被带回孙尚香的临时营帐。孙尚香对他的法眼能力极度好奇——一个无品平民，没有气运，却能精准切断八品武将的气机经纬。她没有审问，而是让随行军医救治林一，并在林一清醒前离开营帐（她有更紧迫的军务）。

林一醒来时发现自己在一顶陌生的军帐里，伤已粗略处理，无人看守，帐外是宜都码头集市的喧嚣声。这看似疏漏，实则是孙尚香的刻意安排——她要看这个"有趣的家伙"在自由状态下会做什么、接触什么人、去什么地方。至少两名孙尚香的亲卫暗中跟踪林一。

**这个设定的叙事价值：**
- 林一以为自己侥幸脱身，实际在棋盘上
- 沈青岚可能是唯一察觉林一被跟踪的人（闻血辨谎 + 掮客直觉）
- 韩烈作为东吴前锋营成员，可能知道孙尚香"放了个人出去"，但不知道具体是谁
- 为后续孙尚香正式现身制造悬念

## 参与角色

| 角色 | 身份 | 在场理由 | 叙事功能 |
|------|------|----------|----------|
| 林一 | 无品流民 | 从孙尚香营帐"脱身"，流入集市 | 视角主角，法眼感知异常 |
| 沈青岚 | 游医/掮客 | 以药贩身份潜伏码头，执行流民网络任务 | 信息操控者，察觉暗线 |
| 韩烈 | 东吴前锋营都伯 | 奉命在宜都码头巡查，兼顾物资征调 | 武力存在，军令与良知的冲突载体 |
| 陈表 | 刘备派驻屯长 | 驻守宜都，维持税卡秩序 | 冲突引爆点，秩序的脆弱代言人 |
| 孙尚香 | 东吴宗室郡主 | 不在场但通过亲卫暗中操盘 | 幕后观察者，悬念制造 |

## 叙事结构

### 设计理念

Agent Team 的核心价值在于独立角色 AI 产生意外的化学反应。因此本场景采用**最小预设、最大自由度**的结构：只锁定开场状态和高潮触发条件，中间过程完全由角色 Agent 自由碰撞。

### 锁定点：开场状态

**Director 撰写开场旁白，确立以下初始条件：**

- **林一**：从集市边缘的军帐方向走入晨雾中的码头。身上残留军帐药味，伤口粗略处理过。他不知道自己被跟踪。法眼未启动，但本能感到集市有结构性的违和感。
- **沈青岚**：已在码头驻扎数日，以游医身份经营药棚。今日有一笔待确认的交易——独臂药贩要转交"某样东西"给北方买家。
- **韩烈**：带小队抵达码头执行巡查与物资征调，同时收到一条模糊指令（与孙尚香放出林一有关，但他不知道细节）。
- **陈表**：如常运作税卡，但最近码头暗流加剧让他越来越不安。今天有一批北方商贩态度强硬。
- **孙尚香**：不在场。至少两名亲卫暗中跟踪林一，定时回报。孙尚香通过亲卫传令，但不直接干预——除非出现她无法忽视的情况。

开场旁白结束后，Director 将场景状态同步给所有角色 Agent，进入 **Free-form 互动**。

### 自由碰撞区（Free-form）

**Director 不预设节拍顺序。** 每一轮，Director 根据叙事动力选择下一个行动的角色，向该角色 Agent 发送当前场景状态，收集其回应，再更新全局状态。

**Director 仅做三件事：**
1. 环境旁白（天气、人群、气味、声音的变化）
2. 选择下一个行动者（基于"谁此刻有最强的行动动机"）
3. 追踪角色状态（林一的法眼代价、韩烈的体力、陈表的心理压力等）

**Director 不做的事：**
- 不预设谁先遇到谁
- 不预设对话内容或行动方式
- 不强制特定冲突路径

### 锁定点：高潮触发条件

当以下任一条件被角色行动自然触发时，Director 切入**旧仓库高潮场景**：

1. **林一的法眼被动开启** — 感知到旧仓库方向的力量异常（"经纬打结"）
2. **独臂药贩的交易发生** — 有角色发现或介入这笔交易
3. **多方势力在同一空间暴露** — 至少三个不同阵营的角色在近距离被迫互动

触发后，Director 撰写过渡旁白将场景推入夜间旧仓库，各角色因各自的理由汇聚于此。仓库内部的不明光源是某种残留的力量痕迹（品级不明，林一的法眼能看到其"经纬"正在缓慢崩解）。

**仓库内的冲突发展、引爆方式、角色间的对抗与合作，全部由 Agent Team 自由碰撞产生。**

### 锁定点：收束条件

当以下任一条件满足时，Director 介入收束：

- 仓库冲突分出明确结果（有人退出、有人受伤、有人暴露身份）
- 互动已达 8-15 个叙事节拍
- 张力自然耗尽

Director 撰写收束旁白，捕捉各角色在事件后的状态变化。**不预设具体结局**——让角色 Agent 的选择决定每个人的走向。

### 场景可用的冲突种子

以下元素已埋入场景和角色设定中，角色 Agent 可自然触发，Director 不强制使用：

- 陈表的税卡与北方商贩的冲突
- 独臂药贩的神秘交易
- 旧仓库的不明光源 / 力量痕迹
- 孙尚香亲卫的暗中跟踪被某人发现
- 韩烈的模糊搜索指令与他实际遇到的情况之间的矛盾
- 有人认出某个不该在此出现的人
- 沈青岚与韩烈的旧识关系在不合适的场合被暴露

## Agent Team 配置

### 团队结构

```
Director（team lead）
├── agent-lin-yi      — 林一视角与决策

├── agent-han-lie      — 韩烈视角与决策
├── agent-chen-biao    — 陈表视角与决策
└── agent-sun-shangxiang — 孙尚香幕后指令（通过亲卫传达）
```

### 每个角色 Agent 的 Prompt 加载

1. 完整角色档案（`characters/<id>.md`）
2. 场景上下文（`scenes/yidu-market.md`）
3. 世界观约束（`design/worldbuilding.md` 核心规则）
4. 风格指南（`design/style-guide.md` 隐喻系统与禁用词）
5. 序章内容（`content/chapter-000.md`，提供前情）
6. 本计划中该角色的叙事节拍与动机
7. "始终以角色身份回应"的指令

### Director 职责

- 撰写开场旁白，确立初始条件后进入 Free-form
- 每轮选择下一个行动者，通过 `SendMessage` 发送当前场景状态
- 撰写环境旁白与过渡叙事（不干预角色决策）
- 追踪角色状态变化（林一的法眼代价、韩烈的体力消耗等）
- 监测高潮触发条件，条件满足时切入旧仓库场景
- 监测收束条件，条件满足时撰写收束旁白
- 收集所有角色响应，编织成连贯的叙事散文

### 互动模式

- 开场旁白：**Director 独写**
- 集市阶段：**Free-form** — 角色自由碰撞，Director 仅做环境旁白和行动者选择
- 旧仓库高潮：**Free-form** — 全自由碰撞
- 收束旁白：**Director 独写**（基于角色 Agent 的最终状态）

## 产出与审阅

### 产出文件
- 草稿：`content/draft-yidu-market-<timestamp>.md`
- 审阅：`content/reviews/review-draft-yidu-market-<timestamp>.md`

### 审阅标准（story-reviewer）
- 角色一致性（25%）：对话行动与档案一致？语言风格保留？
- 叙事张力（25%）：张力自然升级？有明确利益冲突？
- 世界观融洽（20%）：符合三国设定？科幻隐喻自然？无禁用词？
- 文学质感（15%）：散文质量？感官细节？Show-don't-tell？
- 创意新鲜度（15%）：有惊喜？避免套路？

### 判决流程
- ≥ 8 分：保留，编辑为 `content/chapter-001.md`
- 6-7.9 分：针对性修改后重新审阅
- < 6 分：分析失败原因，调整节拍或角色指令后重跑
